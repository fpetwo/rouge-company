## How to read the tables

- **Level** is the required character level. For uniques and set items it already includes the base item's requirement, so it is the level at which you can really wear the item.
- **Tier**: N = normal, Exc = exceptional, Elite = elite. The exceptional and elite versions of a base belong to the same item family and are listed right below it.
- **Max sockets** is the most sockets the base can have. Whether a given item reaches it depends on its item level, because low item levels cap the socket count.
- **Speed** is the weapon speed modifier. Lower is faster: −30 is a very fast weapon, +20 a slow one.

Item names and numbers are game data and belong to Blizzard Entertainment. This site shows no game artwork and has no trading or price features.
